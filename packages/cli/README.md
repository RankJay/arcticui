# arcticui CLI

Add arcticui components to your project with a single command.

## Installation

```bash
npx arcticui init
```

## Usage

### Initialize your project

```bash
npx arcticui init
```

### Add components

```bash
npx arcticui add radial-menu
```

Add multiple components:

```bash
npx arcticui add button card dialog
```

## Configuration

The `init` command creates a `components.json` file in your project root with your preferences.
