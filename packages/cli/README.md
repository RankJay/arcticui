# elasticui CLI

Add elasticui components to your project with a single command.

## Installation

```bash
npx elasticui init
```

## Usage

### Initialize your project

```bash
npx elasticui init
```

### Add components

```bash
npx elasticui add radial-menu
```

Add multiple components:

```bash
npx elasticui add button card dialog
```

## Configuration

The `init` command creates a `components.json` file in your project root with your preferences.
