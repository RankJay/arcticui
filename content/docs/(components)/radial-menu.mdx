## Install

```npm
npx shadcn@latest add @rank/radial-menu
```

## Usage

```tsx
import RadialMenu from "@/registry/rank/ui/radial-menu";
```

Pass a `triggerRef` to the element that opens the menu. Each menu item needs an `id`, `label`, and Lucide-compatible `icon` component.
